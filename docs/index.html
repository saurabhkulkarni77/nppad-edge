🛰️ NPPAD-Edge

A nuclear-plant accident classifier packaged to run under outer-space-like, limited-compute conditions: one CPU core, ≤ 512 MB RAM, a SHA-256-checksummed model bundle, and a runtime that detects corruption in its own memory and falls back to a safe-mode model.

GitHub repo CI runs CI-measured results Benchmarks (local)

The idea

NASA's Intelligent Processing at the Edge story describes Ubotica's CogniSAT: a small companion processor flown with a satellite, running ML at the point of capture instead of downlinking raw data, with protection against radiation-induced corruption. NPPAD-Edge maps that architecture onto a nuclear-plant monitoring payload. The model is the winner of a SOTA study on the NPPAD dataset — MultiRocket + HYDRA random-kernel features with a linear head — its forward transforms re-implemented in pure NumPy and exported to a ~2 MB float16 bundle.

The NumPy transforms are bit-faithful to aeon (max abs feature difference ≤ 7.6e-06 over 50,752 features), so the edge bundle reproduces the study's headline scores exactly on the 240 held-out test windows per window size. The task: classify a 60 s / 120 s window of 88 plant sensor channels (onset-aligned, oracle variables excluded) into 12 accident classes.

Integrity & safe mode

Every bundle file is listed in manifest.json with its SHA-256; the loader refuses a corrupted uplink outright. While running, a checker thread periodically re-digests the live weight arrays — the fault-injection demo flips a bit in memory and the watchdog catches it, switches to the fallback model, and marks subsequent telemetry mode: safe. A corrupted-bundle copy and an in-flight bit flip are both exercised in CI on every push.

Honest limits

This is a simulation of space conditions on ordinary Earth hardware: one CPU core, a memory ceiling, and scripted bit flips stand in for a radiation environment. No radiation testing, no real-time OS, no flight hardware. The sensor stream is a replay of recorded NPPAD test transients and the "downlink" is a local JSONL file.
